# Design System & UI Specifications

## 1. Palette & Colors
- Primary Accent: #DC2626 (Vibrant Crimson Red) — Appetite, action, CTAs.
- Secondary Highlight: #F59E0B (Golden Amber) — Ratings, badges, 3D spotlights.
- Dark Surface: #0F172A (Deep Slate Navy) — Background for 3D card elevation.
- Light Surface: #F8FAFC (Soft Off-White) — Clean day mode contrast.
- Success Accent: #10B981 (Emerald Green) — Wallet credits, completed tracker stages.

## 2. Typography
- Headings: 'Poppins', sans-serif (800 / Extrabold for Hero, 700 / Bold for Section Titles).
- Body & UI: 'Inter', sans-serif (400 / Normal for descriptions, 500 / Medium for labels, 600 / Semi-bold for prices).

## 3. Responsive Breakpoints
- Mobile (< 640px): 1-column 3D cards, bottom fixed checkout CTA, slide-up drawers.
- Tablet (640px - 1024px): 2-column cards, persistent top header.
- Desktop (> 1024px): 3-column / 4-column cards, split-screen live tracker, multi-column KDS kanban.
